Selected Projects

Two projects that reflect Aswinth's range — from a cybersecurity-focused system to a real-world business deployment.

PROJECT 01
VAYUNTRA
Proactive Cybersecurity Anomaly Detection System
Cybersecurity / AI

VAYUNTRA is a cybersecurity-focused system built to proactively identify abnormal and suspicious activity rather than react after the fact. It explores AI-based anomaly detection as the core mechanism for flagging unusual behaviour, paired with a blockchain-integrated layer for storing and verifying security-related records. The goal of that integration is a tamper-resistant, transparent way to preserve data integrity — so that once a security event is logged, it can be trusted and independently verified.
